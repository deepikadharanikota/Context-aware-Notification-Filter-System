Android Setup
Connect your Android phone to NeuralNotify using Tasker.
Every notification gets forwarded to the AI filter automatically — no root required.
What you'll need
1
Tasker app (free APK at tasker.joaoapps.com or Play Store)
2
Notification Access granted to Tasker in Android Settings
3
Phone and PC on the same Wi-Fi network
📥
Import Profile
Download the pre-configured Tasker profile with your server IP already filled in.
Download Tasker XML
http://<server>:8000/device/tasker-xml
Then in Tasker: Long-press Profiles → Import → select file. Enable the profile ✅
Grant Notification Access
1
Open Android Settings → Apps → Tasker
2
Tap Notification Access → Enable
3
Or go to Settings → Notifications → Notification Access → Tasker
✅
All Set!
Tasker is configured. Send yourself a WhatsApp message to verify the pipeline is working.

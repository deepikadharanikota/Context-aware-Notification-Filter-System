🤖 Android Setup (Tasker)

Tasker intercepts every notification on your phone and POSTs it to /push automatically. No root required — just Notification Access permission.

1
Install Tasker from Play Store → grant Notification Access
2
Import the tasker_profile.xml file (included in this project) into Tasker → Long-press Profiles → Import
3
Edit the HTTP action URL to your PC's IP: http://<your-ip>:8000/push
4
Enable the profile — every notification now flows into NeuralNotify in real time ✅
// Tasker sends this JSON on every notification:
{
  "app": "%entryappname",
  "package": "%entryappname",
  "sender": "%entrytitle",
  "message": "%entrytext",
  "context": { "hour": %TIMEH }
}
🍎 iOS Setup (Shortcuts)

iOS Shortcuts can run an automation on notification arrival and POST to NeuralNotify. Requires iOS 15+ and Shortcuts app.

1
Open Shortcuts → Automation tab → + New Automation
2
Choose trigger: App → When [any app] opens notification
3
Add action: Get Contents of URL → Method: POST → URL: http://<your-ip>:8000/push
4
Request body (JSON): {"app":"Shortcut Variable","sender":"Title","message":"Body"}
5
Disable "Ask Before Running" → every notification POSTs silently ✅

🔧 Tasker Setup Steps
1
Install Tasker from Play Store → open app → grant all permissions
2
Go to Android Settings → Apps → Tasker → Notification Access → Enable
3
In Tasker, Long-press Profiles tab → Import Profile → select downloaded XML
4
Enable the NeuralNotify Bridge profile — toggle it ON ✅
5
Receive any notification → watch it appear in the 📡 Live Feed tab above

The android_bridge.py script reads Android notifications over ADB and POSTs them to /push.
